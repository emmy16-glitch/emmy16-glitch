## Featured Projects

### 🔐 [vulnhunter-ai-work](https://github.com/emmy16-glitch/vulnhunter-ai-work)
Authorized, lab-only security assessment platform with governed workflows, deterministic verification, and AI-assisted analysis that stays non-authoritative.

### 🛡️ [auctorail](https://github.com/emmy16-glitch/auctorail)
Authorization rails for autonomous AI agents: exact-action permission checks, short-lived signed permits, replay protection, and tamper-evident execution receipts.

### 🤖 [AgentDesk](https://github.com/emmy16-glitch/AgentDesk)
Task-first AI agent marketplace on BNB Chain that tests agents on bounded tasks before hire and separates evidence states (capability, audition, hire, completion).

### 🌍 [RemoteJobOS](https://github.com/emmy16-glitch/RemoteJobOS)
Cloud-first remote-job operating system with ATS/feed discovery, deterministic matching, Playwright-assisted application workflows, and Supabase/Postgres persistence.

### 🎙️ [Echoo-main](https://github.com/emmy16-glitch/Echoo-main)
Audio-first live broadcasting platform spanning web, mobile, and desktop with LiveKit real-time audio, Node backend services, and recording/transcript workflows.

### ⚙️ [server-dashboard](https://github.com/emmy16-glitch/server-dashboard)
Personal self-hosting control plane for monitoring apps, process control, deployment hooks, incident handling, and audited AI-assisted troubleshooting.
